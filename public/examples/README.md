# Synthetic examples

`synthetic.pdb` and `synthetic.cif` are generated by `node scripts/generate-fixtures.mjs`.
They contain the same 32-residue illustrative backbone: an idealized C-alpha helix
and an extended strand, each with 16 residues. C, O and N coordinates provide a
complete input backbone but are not energy-minimized or chemically authoritative.

These are locally generated test/demo data, not an experimental structure or an
external database download. No HELIX/SHEET annotations are provided: the parser
must compute secondary structure from coordinates. The mmCIF example deliberately
has multi-character original author chain IDs to exercise chain preservation.

Do not use these coordinates for scientific analysis. Real downloaded or private
structures belong in ignored local folders, not this directory.
